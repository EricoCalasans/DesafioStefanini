| [Entrega](SPEC-entrega.md) | README operacional, demonstração e pacote final |

O [mapa de capacidades](../docs/CAPABILITY-MAP.md) mostra dependências e sequência. Os contratos HTTP versionados estão em [contracts](../contracts/README.md).
